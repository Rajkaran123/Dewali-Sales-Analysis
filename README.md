
Diwali Sales Analysis using Python

 📌 Project Overview

This project focuses on analyzing Diwali sales data using Python to understand customer purchasing behavior, sales trends, and business insights during the festive season.



 Objectives

* Perform data cleaning and preprocessing
* Analyze customer purchase behavior
* Visualize sales trends using graphs and charts
* Generate business insights from the dataset

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook


 Data Collection

* Imported Diwali sales dataset in CSV format.

Data Cleaning

* Removed null values
* Checked duplicate records
* Corrected data types
* Handled missing values

Exploratory Data Analysis (EDA)

Performed analysis on:

* Gender-wise sales
* Age group analysis
* State-wise orders
* Occupation analysis
* Product category analysis
* Marital status analysis


- Key Insights

* Female customers contributed more to total sales.
* Most buyers belonged to the age group of 26–35 years.
* Uttar Pradesh, Maharashtra, and Karnataka had the highest number of orders.
* IT, Healthcare, and Aviation sectors showed strong purchasing behavior.
* Food, Clothing, and Electronics categories performed well during Diwali sales.
